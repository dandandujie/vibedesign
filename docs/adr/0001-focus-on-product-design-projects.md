# 聚焦产品设计项目

VibeDesign 定位为面向独立开发者和小型产品团队的本地 AI 前端 UI/UX 设计工作台，核心闭环是将产品意图演化为具有统一设计语言、可交互、可迭代并可交付给编码 Agent 的多页面产品原型。它只负责完整表达和验证前端体验，其中的数据、权限与业务结果可以模拟；后端、数据库、鉴权及业务系统实现不属于其职责。单页设计是最小项目；网页和 App 产品设计属于核心范围，海报、财报、社交轮播、复杂演示文稿等通用内容创作能力不进入核心路线。我们选择这一边界，而不是继续成为 Claude Design 的逐项复刻或类似 OpenDesign 的万能创作平台，以便把有限投入用于补全项目级 UI/UX 设计闭环。
