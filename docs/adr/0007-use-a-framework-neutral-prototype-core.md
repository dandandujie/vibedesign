# 使用框架无关的统一原型核心

VibeDesign 统一以浏览器标准技术构建 Web、桌面和移动 App 的可运行 UI/UX 原型，并支持直接导出 HTML/ZIP；核心编辑器不同时维护 React、Next.js、Vue、React Native、Flutter 或 SwiftUI 等多套运行时。设计被接受后，可由编码 Agent 通过可选交付适配将框架无关原型转换到目标技术栈。这个边界参考 Claude Design 的独立 HTML、ZIP 与 Claude Code 交接流程，以及 OpenDesign 以 HTML Artifact 为默认原型、再通过可选场景插件转换到目标框架的做法。
